# LinkedIn Notifyer Client

![App Logo](https://raw.githubusercontent.com/kekonline/LinkedIn_Notifyer_Client/refs/heads/master/src/assets/splash_screen_logo.png)

This repository was originally part of a full-stack project designed to provide users with job notifications scraped from LinkedIn. The **LinkedIn_Notifyer_Client** served as the front-end application, enabling users to interact with the system seamlessly.

## 🔗 Project Evolution

As the project matured, the functionality of this client was merged into the server-side application, **LinkedIn_Notifyer_Server**, to streamline development and consolidate features. 

If you're interested in exploring the complete project and its capabilities, check out the server repository:  
[**LinkedIn_Notifyer_Server**](https://github.com/kekonline/LinkedIn_Notifyer_Server)

## 🛠️ Technologies Used

The client was built using the following technologies:  
- **React** for dynamic and responsive user interfaces  
- **TypeScript** for type safety and developer-friendly code  
- **Tailwind CSS** for efficient and modern styling  
- **Vite** for fast development and build processes  

## 🚀 Key Features

- A user-friendly interface for managing job notifications  
- Integration with APIs to fetch LinkedIn job listings  
- Real-time notifications for job updates  
- Search and filter functionality for job preferences
